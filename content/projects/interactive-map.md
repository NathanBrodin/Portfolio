For the Software Development using DevOps class, I made an app that lets you look for cities around you: you click on the map to search, change the search filters in a side panel, and click on a city to see more details about it.

All on [Docker](https://www.docker.com/) (one `docker compose up` and it runs), with CI/CD, docs with architecture diagrams, great docs. Client with [Next.js](https://nextjs.org/), [Tailwind CSS](https://tailwindcss.com/), and [Cypress](https://www.cypress.io/) for E2E testing. Backend with [ASP.NET](https://dotnet.microsoft.com/apps/aspnet) Core, [C#](https://learn.microsoft.com/en-us/dotnet/csharp/) and xUnit for unit tests, and [PostgreSQL](https://www.postgresql.org/) database. OpenAPI specs, and great code coverage, with the pipeline and coverage badges directly in the README.

So this was a full stack app with all of the great software engineering practices.
